# Real-Time Chat Application (MERN Stack) – Project Documentation

## 1. Project Overview

A **Real-Time Chat Application** allows users to:

* Register and login
* Send and receive messages instantly
* Create conversations
* View online users
* Store chat history in the database

# 5. Backend Development

## Step 1: Initialize Backend

Create backend folder.

```
mkdir backend
cd backend
npm init -y
```

Install dependencies

```
npm install express mongoose cors dotenv bcrypt jsonwebtoken socket.io
npm install nodemon --save-dev
```

---

## Step 2: Create Express Server

Create `server.js`

Main responsibilities:

* Start server
* Connect database
* Setup Socket.IO
* Load routes

---

## Step 3: Connect MongoDB

Use Mongoose to connect.

Create:

```
config/db.js
```

Responsibilities:

* Connect to MongoDB
* Handle connection errors

---

## Step 4: Create Database Models

Inside **models folder**

### User Model

Fields:

* username
* email
* password
* profilePic
* createdAt

### Conversation Model

Fields:

* members (array of user IDs)

### Message Model

Fields:

* conversationId
* senderId
* text
* createdAt

---

## Step 5: Create Authentication API

Create routes:

```
routes/auth.js
```

Endpoints:

```
POST /api/auth/register
POST /api/auth/login
```

Features:

* Password hashing using bcrypt
* Token generation using JSON Web Token

---

## Step 6: Conversation APIs

Create:

```
routes/conversations.js
```

Endpoints:

```
POST /create conversation
GET /user conversations
```

---

## Step 7: Message APIs

Create:

```
routes/messages.js
```

Endpoints:

```
POST /send message
GET /conversation messages
```

---

# 6. Real-Time Chat using Socket.IO

Setup Socket.IO inside the server.

Features:

Events:


# 10. Real-Time Messaging

Use **Socket.IO client**.

Process:

1. User connects to socket
2. Server registers user
3. When message sent
4. Server broadcasts message
5. Receiver instantly gets message
