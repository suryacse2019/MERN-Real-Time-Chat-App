Below is a **Database Schema Diagram for a Real-Time Chat Application** using **MongoDB** with **Mongoose**.
This schema shows the **relationship between Users, Conversations, and Messages**. 📊

---

# 1. Database Collections Overview

The chat application contains **3 main collections**:

1. **Users**
2. **Conversations**
3. **Messages**

---

# 2. Schema Relationship Diagram

```
        USERS
   -----------------
   _id (ObjectId)
   username
   email
   password
   profilePic
   createdAt
        │
        │
        │ 1..*
        │
        ▼
   CONVERSATIONS
   -----------------
   _id (ObjectId)
   members [userId]
   createdAt
        │
        │ 1..*
        │
        ▼
     MESSAGES
   -----------------
   _id (ObjectId)
   conversationId
   senderId
   text
   createdAt
```

Explanation:

* **One user** can be part of **multiple conversations**
* **One conversation** contains **many messages**
* Each **message belongs to one conversation**

---

# 3. Users Collection

Stores all registered users.

```
Users
{
  _id: ObjectId,
  username: String,
  email: String,
  password: String,
  profilePic: String,
  createdAt: Date
}
```

Example:

```
{
  "_id": "u123",
  "username": "Rahul",
  "email": "rahul@email.com",
  "password": "hashed_password",
  "profilePic": "image.png",
  "createdAt": "2026-03-17"
}
```

---

# 4. Conversations Collection

Stores chat relationships between users.

```
Conversations
{
  _id: ObjectId,
  members: [userId1, userId2],
  createdAt: Date
}
```

Example:

```
{
  "_id": "c101",
  "members": ["u123","u456"],
  "createdAt": "2026-03-17"
}
```

---

# 5. Messages Collection

Stores individual chat messages.

```
Messages
{
  _id: ObjectId,
  conversationId: ObjectId,
  senderId: ObjectId,
  text: String,
  createdAt: Date
}
```

Example:

```
{
  "_id": "m555",
  "conversationId": "c101",
  "senderId": "u123",
  "text": "Hello!",
  "createdAt": "2026-03-17"
}
```

# 7. Optional Advanced Fields (For Better Chat Apps)

You can also add:

### Users

* lastSeen
* status (online/offline)

### Conversations

* lastMessage
* updatedAt

### Messages

* messageType (text/image/file)
* seenStatus

---

✅ **Final Flow**

1. User registers → stored in **Users collection**
2. Two users start chat → **Conversation created**
3. Messages sent → stored in **Messages collection**
4. Messages retrieved using **conversationId**
